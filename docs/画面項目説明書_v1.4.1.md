# TksToKintone 画面項目説明書（バージョン 1.4.1）

本書は TksToKintone バージョン 1.4.1 の各画面に表示される項目（入力欄・ボタン・チェックボックスなど）の意味を一覧で説明します。操作の流れは [操作説明書_v1.4.1.md](操作説明書_v1.4.1.md) を参照してください。

---

## 1. 機能選択画面

タイトル：`TKS OLAP to kintone 1.4.1`

| 項目 | 種類 | 説明 |
| --- | --- | --- |
| OLAPログインID | 入力欄 | TKS OLAP のログイン ID。 |
| OLAPパスワード | 入力欄（伏字） | TKS OLAP のパスワード。ログイン成功時に保存され次回自動入力。 |
| kintoneログインID | 入力欄 | kintone 登録処理で使うログイン ID。 |
| kintoneパスワード | 入力欄（伏字） | kintone 登録処理で使うパスワード。 |
| 伝票作成・印刷 | ボタン | OLAP ログイン検証後、伝票作成・印刷画面を開く。OLAP 情報入力で有効化。 |
| Kintone登録処理 | ボタン | OLAP ログイン＋kintone 接続検証後、登録画面を開く。両方の情報入力で有効化。 |
| ⚙（設定） | ボタン | 共通設定ダイアログを開く。 |
| 設定フォルダを開く | ボタン | ProgramData 設定フォルダを開く（デバッグ表示時のみ）。 |
| ログフォルダを開く | ボタン | ログフォルダを開く（デバッグ表示時のみ）。 |
| workフォルダを開く | ボタン | 作業フォルダを開く（デバッグ表示時のみ）。 |

## 3. 伝票作成・印刷画面

タイトル：`伝票作成・印刷 — TKS OLAP to kintone 1.4.1`

### 3.1 画面上部

| 項目 | 種類 | 説明 |
| --- | --- | --- |
| 受注一覧 | 見出し | 受注行を一覧表示する表のタイトル。 |
| 受注No検索 | 入力欄 | 追加したい受注 No を入力。 |
| 選択受注No追加 | ボタン | 入力した受注 No の行を追加。 |
| 登録状態 | フィルタ | `未登録` / `登録完了` / `すべて` で行を絞り込み。 |
| 全選択 | チェック | 全行の `選択` をまとめて ON/OFF。 |
| 行追加 | ボタン | 空行を 1 行追加。 |
| ⚙（印刷する伝票設定） | ボタン | 印刷する伝票設定ダイアログを開く。 |
| 選択PDF作成 | ボタン | `選択` 行の PDF をまとめて作成。 |
| 選択プレビュー | ボタン | `選択` 行をまとめてプレビュー。 |
| 選択印刷 | ボタン | `選択` 行をまとめて印刷。 |

### 3.2 受注一覧の列（COLUMN_LABELS）

| 列 | 種類 | 説明 |
| --- | --- | --- |
| 選択 | チェック | まとめ操作の対象にする。 |
| 受注No | 入力欄 | 受注 No（例: 5218869）。 |
| 取り直し | ボタン | 受注 No で OLAP を再取得。設定・指図書編集内容は保持。 |
| 仕上日 | 日付＋`なし`チェック | 伝票に印字する仕上日。`なし` で空欄。 |
| AM・PM | ラジオ | `なし` / `AM` / `PM`（初期 AM）。 |
| 加工名 | チェック群 | 印字する加工名を選択（初期全 OFF）。 |
| 印刷する伝票 | チェック群 | 作成・印刷する伝票種類（3.4 参照）。 |
| 指図書編集 | ボタン | 指図書編集画面を開く。 |
| PDF作成 | ボタン | PDF を出力先フォルダへ保存。 |
| プレビュー | ボタン | アプリ内プレビューで表示（保存なし）。 |
| 印刷 | ボタン | 印刷ダイアログで印刷。 |
| Kintone登録 | ボタン | Kintone 登録画面が開いていれば `受注No追加`。追加後は緑色 `追加済`。 |

### 3.3 画面下部

| 項目 | 種類 | 説明 |
| --- | --- | --- |
| PDF出力先 | 入力欄 | PDF 作成時の保存先フォルダ。 |
| 参照 | ボタン | 出力先フォルダを選択。 |
| 戻る | ボタン | 機能選択画面へ戻る。 |

### 3.4 伝票の種類

| ID | 名称 |
| --- | --- |
| 01 | 売上伝票 |
| 02 | 工場控 |
| 03 | 指図書(1) |
| 04 | 指図書(2) |
| 05 | 梱包明細書 |
| 06 | 配送指示書 |
| 07 | 納品書 |
| 08 | 受領書 |

## 5. 指図書編集画面

タイトル：`指図書編集 — 受注No <受注No>`

### 5.1 ツールバー

| 項目 | 種類 | 説明 |
| --- | --- | --- |
| 選択 | ツール | 選択・移動・リサイズ。 |
| テキスト | ツール | ドラッグ範囲にテキストボックス作成。ダブルクリックで編集。 |
| 線 | ツール | ドラッグで直線を作成。 |
| 四角 | ツール | ドラッグで四角形を作成。 |
| 丸 | ツール | ドラッグで楕円を作成。 |
| 線幅 | 数値 | 選択中オブジェクトの線幅。 |
| 文字サイズ | 数値 | 選択中テキストの文字サイズ。 |
| 画像挿入 | ボタン | ファイルから画像を挿入。 |
| 貼り付け | ボタン | クリップボードの画像を貼り付け（Ctrl+V）。 |
| 削除 | ボタン | 選択オブジェクトを削除（赤）。 |
| 保存 | ボタン | 編集内容を保存（緑）。閉じない。 |
| 保存して閉じる | ボタン | 保存してから閉じる（緑）。 |
| 閉じる | ボタン | 画面を閉じる。未保存時は確認。 |
| 全画面 | ボタン | 全画面表示／最大化表示の切替（全画面時は「全画面解除」）。 |

### 5.2 画像加工パネル

| 項目 | 種類 | 説明 |
| --- | --- | --- |
| 背景を透過（rembg） | ボタン | AI で被写体を切り抜き背景を透過。 |
| 背景を透過（閾値） | ボタン | RGB 閾値で背景色を透過。 |
| 二値化 | ボタン | 閾値で白黒に変換。 |
| 背景を戻す | ボタン | 加工前の画像へ戻す。 |
| 閾値設定 | ボタン | 二値化／閾値透過の RGB 閾値を設定。 |

### 5.3 反映先パネル（画面左）

| 項目 | 種類 | 説明 |
| --- | --- | --- |
| 反映先 | 見出し | 編集オブジェクトを反映する伝票を選ぶパネル。 |
| 標準 / 全伝票 / 指図書のみ / 梱包のみ | ボタン | 組込テンプレート。標準＝指図書(1)(2)・梱包明細書。 |
| ＋ テンプレ登録 | ボタン | 反映先テンプレートを新規登録。 |
| （各テンプレート右クリック） | メニュー | `編集` / `削除`（組込は削除不可）。 |

### 5.4 主なショートカット

| キー | 動作 |
| --- | --- |
| Delete | 選択オブジェクトを削除 |
| Ctrl+A | 編集オブジェクトを全選択 |
| Ctrl+Z / Ctrl+Y | 元に戻す／やり直し |
| Ctrl+V | クリップボードの画像を貼り付け |
| Esc | 選択ツールへ戻る（全画面時は解除） |

## 6. Kintone 登録処理画面（メイン画面）

タイトル：`TKS OLAP to kintone 1.4.1`

### 6.1 入力欄

| 項目 | 種類 | 説明 |
| --- | --- | --- |
| TKS_CLIENT_MODE | 表示 | TKS 接続方式（mock / http）。デバッグ表示時のみ。 |
| Kintone接続先 | 表示 | 現在の登録先（本番／テスト）。デバッグ表示時のみ。 |
| ProgramDataフォルダ | 表示 | 設定・ログの格納先パス。デバッグ表示時のみ。 |
| 受注No | 入力欄 | 1 行 1 件、またはカンマ区切りで複数指定。 |
| 仕上日 | 日付＋`なし`チェック | 登録する仕上日。`なし` で空欄。 |
| 出荷区分 | 選択 | 出荷区分の候補から選択。 |
| DRY_RUN | チェック | ON で登録前確認画面を表示。OFF で確認なし登録。 |

### 6.2 操作ボタン

| 項目 | 種類 | 説明 |
| --- | --- | --- |
| 実行 | ボタン | 取得・変換し、DRY_RUN に応じて確認画面表示または登録。 |
| ⚙（設定） | ボタン | 設定ダイアログを開く。 |
| TKS接続テスト | ボタン | OLAP ログインの疎通確認（デバッグ表示時）。 |
| OLAP取得テスト | ボタン | OLAP 取得のみ実行（デバッグ表示時）。 |
| 加工名マスタ | ボタン | 加工名マスタ管理画面を開く。 |
| 得意先ヘッダー設定 | ボタン | 得意先ラベル・判定文字列を設定。 |
| 古いファイル削除 | ボタン | 保存日数より古いログ等を削除。 |
| 設定フォルダを開く | ボタン | 設定フォルダを開く（デバッグ表示時）。 |
| ログフォルダを開く | ボタン | ログフォルダを開く（デバッグ表示時）。 |
| workフォルダを開く | ボタン | 作業フォルダを開く（デバッグ表示時）。 |
| ログ | 表示 | 実行ログ（デバッグ表示時）。 |
| 結果 | 表示 | 実行結果メッセージ。 |

## 10. 加工名マスタ管理画面

タイトル：`加工名マスタ管理`

| 項目 | 種類 | 説明 |
| --- | --- | --- |
| 行追加 / 行削除 | ボタン | マスタ行の追加・削除。 |
| CSVインポート | ボタン | CSV からマスタを取り込み（方式選択あり）。 |
| CSVエクスポート | ボタン | マスタを CSV へ出力。 |
| バックアップ作成 | ボタン | 現在のマスタをバックアップ。 |
| バックアップから復元 | ボタン | バックアップを選んで復元。 |

マスタ列：メーカー識別掛率集計コード、メーカー識別コード、掛率集計コード、掛率集計名称、掛率集計略称、加工名、得意先1〜4。加工名判定は掛率集計コードを優先し、空のときのみ掛率集計名称で判定します。
