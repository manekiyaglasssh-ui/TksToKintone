# TksToKintone ユーザー向け簡易マニュアル

## 目的

TKS OLAPから伝票番号に紐づく加工・素板データを取得し、東大阪工場生産進捗のkintoneアプリへ登録します。

## 起動

1. デスクトップまたはスタートメニューから `TksToKintone` を起動します。
2. 自動で更新確認が行われます。新しいバージョンがある場合だけ確認画面が表示されます。
3. 更新する場合は画面の指示に従ってください。最新の場合は何も表示されません。

## 基本入力

1. `OLAPログインID` を入力します。
2. `OLAPパスワード` を入力します。
   - 右側の目のアイコンを押すと、入力したパスワードを一時的に表示できます。
   - 初回は空白です。TKSログインに成功すると保存され、次回起動時から自動入力されます。
3. `伝票番号` を入力します。
   - 1行に1件ずつ入力できます。
   - カンマ区切りでも入力できます。
4. `仕上日` を選択します。
   - 入力欄またはカレンダーアイコンを押すとカレンダーが表示されます。
5. `出荷区分` を選択します。

## 登録前に確認して登録する

通常は `DRY_RUN` をONにして実行します。

1. `DRY_RUN` がONになっていることを確認します。
2. `実行` を押します。
3. TKSからデータ取得後、登録前確認画面が表示されます。
4. 登録前確認画面で、伝票番号ごとの `仕上日` と `出荷区分` を確認します。
5. 必要に応じて `仕上日` または `出荷区分` を変更します。
   - 変更内容は、同じ受注Noの全レコードに反映されます。
6. kintoneへ登録する場合は `登録` を押します。
7. 登録しない場合は `登録キャンセル` を押します。

## 確認画面なしで登録する

登録前確認画面を出さずに登録する場合だけ、`DRY_RUN` をOFFにします。

1. `DRY_RUN` をOFFにします。
2. 入力内容を確認します。
3. `実行` を押します。

`DRY_RUN` OFFでは、確認画面を表示せずにkintoneへ登録します。

## kintone登録の動き

kintone登録では `検索キー` を使います。

- 同じ検索キーのレコードが既にある場合は更新します。
- 同じ検索キーのレコードがない場合は追加します。

## 設定

画面右上の `設定` から以下を変更できます。

- テーマカラー
  - システム
  - ライト
  - ダーク
- Kintone接続先
  - 本番
  - テスト
- 高度な設定
  - ログ保存日数
  - 加工抽出ロジックの抽出条件
  - 素板抽出ロジックの抽出条件
- バージョン情報
- 更新確認

## Kintone接続先

登録先は設定画面の `Kintone接続先` で切り替えます。

- `本番`: 東大阪工場生産進捗
- `テスト`: 【テスト】東大阪工場生産進捗

初期値は `本番` です。

本番へ登録する前は、入力した伝票番号、仕上日、出荷区分を必ず確認してください。

## 高度な設定

`高度な設定を開く` から、ログ保存日数とOLAP抽出条件を変更できます。

- ログ保存日数
  - 指定日数より古いログを起動時に自動削除します。
  - 初期値は30日です。
- 加工抽出ロジック / 素板抽出ロジック
  - 通常は変更不要です。
  - 抽出条件を変更した場合は、次回実行時から反映されます。
  - `初期値に戻す` を押すと、テンプレートの値に戻ります。

## 更新確認

設定画面の `更新確認` を押すと、手動で新しいバージョンを確認できます。

新しいバージョンがある場合は確認画面が表示されます。更新時はアプリを終了し、外部更新処理で更新ファイルをダウンロードしてから、インストーラで自動更新してアプリを再起動します。

## よくある操作

### パスワードを確認したい

`OLAPパスワード` 欄の右側にある目のアイコンを押します。もう一度押すと非表示に戻ります。

### 仕上日を変更したい

トップ画面または登録前確認画面の `仕上日` 欄を押して、カレンダーから日付を選択します。

### 登録せずに内容だけ確認したい

`DRY_RUN` をONにして `実行` し、登録前確認画面で `登録キャンセル` を押します。

## エラー時の確認

エラーが出た場合は、画面下部の結果表示を確認してください。

登録に失敗したレコードがある場合は、エラーCSVが作成されます。必要に応じて管理者へ連絡してください。

# バージョン 1.5.13 の追加機能

## SumatraPDFの導入と再導入

SumatraPDFはTksToKintoneとは別のWindowsアプリとして、セットアップ時に必要な場合だけ自動導入されます。アプリ更新時にも確認されるため、通常は個別の操作は不要です。印刷時に「SumatraPDFが見つかりません」と表示された場合は、TksToKintoneのセットアップを再実行してください。TksToKintoneをアンインストールしてもSumatraPDFは残ります。

# バージョン 1.5.12 の追加機能

## 伝票加工名の行別設定

設定画面の「伝票加工名設定」で、伝票へ表示する加工名を1～12行目ごとに変更できます。表示名だけが変わり、内部の加工判定やKintone登録値には影響しません。

## 指図書編集の操作改善

ドラッグした範囲に合わせて文字サイズを調整できます。テキストは右クリックの「編集」から編集でき、リサイズハンドルで枠を変更すると文字サイズも追従します。小さい文字、細い線、小さいオブジェクトも選択しやすくなりました。

お気に入りオブジェクトは登録時の配置位置を保持します。左ペインの「反映先」と「お気に入り」は、それぞれのセクション内でドラッグ＆ドロップして並び替えられ、順序は次回起動後も維持されます。セクション間の移動はできません。

編集画面のプレビューでは、保存前の内容をそのまま確認できます。

# バージョン 1.5.11 の追加機能

## 画面を先に操作できる段階読込

指図書編集画面は背景生成やフォント一覧の準備を待たずに表示されます。伝票一覧とKintone登録前確認画面は、最初の10件を表示した時点で内容確認、スクロール、検索などを操作でき、残りを10件単位で読み込みます。Kintoneへの登録は、全レコードの確認と検証が完了するまで実行できません。

## PDF・フォント表示の改善

日本語フォント、TTC内のスタイル別フェイス、文字ごとのglyph fallbackを見直し、フォントと太字・斜体・下線・取り消し線をPDF、プレビュー、印刷へより正確に反映します。PDF生成、プレビュー、印刷では保存済みの最新編集内容を再読込し、古い編集内容やプレビューキャッシュが使われないよう改善しました。

# バージョン 1.5.9 の追加機能

## OP区分による上段㎡の表示

売上伝票、工場控、納品書では、明細のOP区分が `00`、`01`、`02` の場合だけ、単価列・金額列の上段に面積（㎡）を表示します。それ以外のOP区分では上段の㎡だけを空欄にし、単価、明細金額、合計金額は伝票設定の「単価表示」に従って表示します。

## 指図書テキストの書式

指図書編集画面の上部ツールバーには、左からフォント名、文字サイズ、`B`（太字）があります。テキストを選択して変更するとそのテキストへ即時反映され、何も選択していない場合や非テキストだけを選択している場合は次に作成するテキストの既定書式になります。文字サイズは候補選択と直接入力に対応し、4～200ptの範囲で指定できます。

選択した書式は保存・再読込、Undo／Redo、コピー、PDF出力でも維持されます。インストールされていないフォントを含む保存データは、安全な既定フォントで表示・出力します。

フォント欄の左にある `☆` を押すと、現在のフォントをお気に入りへ登録できます。登録後は `★` になり、もう一度押すと解除します。背景色・枠線はなく、文字アイコンだけで状態を示します。登録したフォントは同じフォント一覧上部の「★ お気に入り」へ登録順で表示され、その下の「すべてのフォント」にはOSの全フォントが表示されます。お気に入りの追加・解除そのものはUndo／Redoの対象になりません。

`装飾` メニューでは太字、斜体、下線、取り消し線を同時に設定できます。ショートカットは太字 `Ctrl+B`、斜体 `Ctrl+I`、下線 `Ctrl+U`、取り消し線 `Ctrl+5` です。キャンバス上のテキストを右クリックし、「文字装飾」からも同じ設定を変更できます。

# 伝票の範囲取得と単価表示（1.5.8）

伝票作成・印刷画面の先頭にある受注No入力欄を右クリックし、「範囲指定」を選ぶと、開始・終了受注Noを両端に含めて連続取得できます。数字のみのほか、`C405113` や `AB001` のような英字プレフィックス付き受注Noにも対応し、末尾の数字だけを増加させます。開始・終了の英字部分は大文字・小文字を区別せず一致している必要があります。生成時は開始側の英字表記と数値部分の先頭ゼロを維持します。一度に取得できるのは500件までです。101〜500件は注意確認後に開始します。処理中は進捗・成功件数・失敗件数を表示し、中止要求後は処理中の1件が終わった時点で停止します。

完了画面では登録成功を左、登録失敗を右に表示します。それぞれのコピーボタンは、受注Noだけを1行1件でクリップボードへコピーします。

伝票設定の「単価表示」では「従来条件に従う」「常に表示する」「常に表示しない」を選べます。設定は単価・明細金額・金額列下部の合計金額へまとめて適用されます。「常に表示する」でも元の単価・金額が空欄なら値は作成しません。
