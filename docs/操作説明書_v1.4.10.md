# TksToKintone 操作説明書（バージョン 1.4.10）

本書は TksToKintone バージョン 1.4.10 の操作手順を説明します。各画面の項目の詳細は [画面項目説明書_v1.4.10.md](画面項目説明書_v1.4.10.md) を参照してください。

---

## 1. アプリの概要

TksToKintone は、TKS OLAP から受注データを取得して次の 2 つの業務を行う Windows 向け GUI アプリです。

- **伝票作成・印刷**：受注 No ごとに売上伝票・指図書・梱包明細書などの伝票 PDF を作成・プレビュー・印刷します。指図書はアプリ上で注記・図形・画像を書き込んで編集できます。
- **Kintone 登録処理**：取得した加工・素板データを変換し、kintone の生産進捗アプリへ登録します。

起動するとまず**機能選択画面**が表示され、ここからどちらの機能を使うかを選びます。

---

## 2. 起動とログイン（機能選択画面）

1. デスクトップまたはスタートメニューから `TksToKintone` を起動します。
2. 機能選択画面が表示されると、自動でバージョンの更新確認が実行されます。新しいバージョンがある場合のみ確認ダイアログが表示されます。最新の場合は何も表示されません。
3. **OLAPアカウント** に `OLAPログインID` と `OLAPパスワード` を入力します。
   - 入力すると `伝票作成・印刷` ボタンが押せるようになります。
   - 一度ログインに成功すると保存され、次回起動時は自動入力されます。
4. **kintoneアカウント** に `kintoneログインID` と `kintoneパスワード` を入力します。
   - これは `Kintone登録処理` で使用します。OLAP と kintone の両方が入力されると `Kintone登録処理` ボタンが押せるようになります。
5. 使う機能のボタンを押します。
   - `伝票作成・印刷`：OLAP ログインを検証してから伝票画面を開きます。
   - `Kintone登録処理`：OLAP ログインと kintone 接続を検証してから登録画面を開きます。

> 子画面（伝票画面・Kintone 登録画面）を開いている間は、対応するログイン情報欄は変更できなくなります。子画面を閉じると機能選択画面が再び前面に表示されます。

---

## 3. 伝票作成・印刷

機能選択画面で `伝票作成・印刷` を押すと、受注一覧の表形式画面が開きます（起動時は最大化表示）。

### 3.1 受注を一覧へ追加する

- `行追加` を押すと空の行が増えます。各行の `受注No` 欄に受注 No を入力します。
- 画面上部の `受注No検索` 欄に受注 No を入力して `選択受注No追加` を押すと、その受注 No の行をまとめて追加できます。
- 受注 No を入力すると、PDF 作成・プレビュー時に自動で OLAP からデータを取得します。

### 3.2 行ごとの設定

各行で以下を設定します。

- **仕上日**：カレンダーから日付を選びます。`なし` にチェックすると仕上日を空欄にできます。
- **AM・PM**：`なし` / `AM` / `PM` から選びます（初期値 AM）。
- **加工名**：チェックした加工名が伝票に印字されます（初期は全 OFF）。
- **印刷する伝票**：作成・印刷する伝票の種類をチェックします（売上伝票・工場控・指図書(1)・指図書(2)・梱包明細書・配送指示書・納品書・受領書）。新規行の初期チェックは「印刷する伝票設定」で変更できます。

### 3.3 取り直し（最新データの再取得）

`取り直し` ボタンを押すと、その行の受注 No で OLAP データを再取得します。仕上日・AM/PM・加工名・印刷する伝票のチェックや、指図書編集の内容はそのまま保持されます。

### 3.4 伝票の作成・確認・印刷

各行のボタンで操作します。

- `PDF作成`：その行の伝票 PDF を、画面下部の `PDF出力先` フォルダへ保存します。
- `プレビュー`：PDF を保存せずアプリ内のプレビュー画面で表示します（拡大・縮小・100%・印刷・閉じる）。
- `印刷`：印刷ダイアログを開いて印刷します。

複数行をまとめて処理する場合は、各行の `選択` にチェックを入れ、上部の `選択PDF作成` / `選択プレビュー` / `選択印刷` を使います。`全選択` で全行をまとめて選択／解除できます。

`PDF出力先` は `参照` ボタンでフォルダを指定します。指定内容は保存され次回も使われます。

### 3.5 指図書編集

`指図書編集` を押すと、指図書(1) を背景にした編集画面が開きます。詳細は「4. 指図書編集画面」を参照してください。

### 3.6 印刷する伝票設定

画面右上の `⚙`（印刷する伝票設定）を押すと設定ダイアログが開きます。

- **新規行の印刷する伝票（初期チェック）**：行追加時に最初からチェックしておく伝票種類を指定します。
- **OLAPキャッシュ保存期間（日）**：取得した OLAP データの保存日数（既定 7 日）。
- **レコード情報保持期間（日）**：登録状態などの保持日数。

### 3.7 Kintone 登録処理画面との連携

`Kintone登録処理` 画面を同時に開いていると、各行右端のボタンが `受注No追加` として機能し、その受注 No を kintone 登録画面の対象に追加できます。追加済みの行は緑色の `追加済` 表示になります。kintone 登録が完了すると登録状態が `登録完了` に更新されます。上部の `登録状態` でフィルタできます。

`戻る` を押すと機能選択画面へ戻ります。

## 4. 指図書編集画面

指図書(1) を背景に、注記テキストや図形・画像を書き込めます。書き込んだ内容は受注 No ごとに保存され、PDF 作成時に対象の伝票へ重ね描きされます。

### 4.1 ツールバーの作図ツール

- `選択`：オブジェクトの選択・移動・リサイズを行います。
- `テキスト`：ドラッグした範囲にテキストボックスを作成します。ダブルクリックで文字を編集します。
- `線` / `四角` / `丸`：ドラッグで図形を作成します。
- `線幅` / `文字サイズ`：選択中のオブジェクトへ即時反映します。
- `画像挿入`：ファイルから画像を挿入します。`貼り付け`（Ctrl+V）でクリップボードの画像も貼れます。

### 4.2 画像の背景加工

選択した画像に対して以下が行えます。

- `背景を透過（rembg）`：AI で被写体を切り抜き背景を透過します。
- `背景を透過（閾値）`：指定した RGB 閾値で背景色を透過します。
- `二値化`：閾値で白黒に変換します。
- `閾値設定`：二値化／閾値透過で使う RGB 閾値を設定します。
- `背景を戻す`：加工前の画像へ戻します。

### 4.3 反映先テンプレート

画面左の `反映先` パネルで、選択中／新規オブジェクトをどの伝票へ反映するかを切り替えます。組込テンプレート（標準＝指図書(1)(2)・梱包明細書、全伝票、指図書のみ、梱包のみ）に加え、`＋ テンプレ登録` で独自のテンプレートを作れます。テンプレートボタンの右クリックで編集・削除できます（組込テンプレートは削除不可）。各オブジェクト左上には反映先を示す色付きバッヂが表示されます。

### 4.4 編集の操作

- `Delete`：選択オブジェクトを削除します。`削除` ボタンも同じです。
- `Ctrl+A`：編集オブジェクトを全選択します。
- `Ctrl+Z` / `Ctrl+Y`：元に戻す／やり直し。
- `Esc`：選択ツールへ戻る（全画面時は全画面解除）。
- `全画面`：全画面表示と最大化表示を切り替えます。

### 4.5 保存と終了

- `保存`：編集内容を保存します（画面は閉じません）。
- `保存して閉じる`：保存してから画面を閉じます。
- `閉じる`：閉じます。未保存の変更がある場合は「保存して閉じる／保存せずに閉じる／キャンセル」を確認します。

## 5. Kintone 登録処理

機能選択画面で `Kintone登録処理` を押すと、登録用のメイン画面が開きます。

### 5.1 入力

1. `受注No` を入力します。1 行 1 件、またはカンマ区切りで複数指定できます。
2. `仕上日` を選びます。`なし` にチェックすると空欄になります。
3. `出荷区分` を候補から選びます。

### 5.2 登録前確認をして登録する（推奨）

`DRY_RUN` を ON にしておくと、登録前に確認画面が表示されます。

1. `DRY_RUN` が ON であることを確認します。
2. `実行` を押します。TKS からデータを取得して変換します。
3. **登録前確認画面**で、受注 No ごとの `受注No` `仕上日` `出荷区分` を確認します。
   - 仕上日・出荷区分はここで変更でき、変更は同じ受注 No の全レコードへ反映されます。
   - `受注No絞り込み` で表示を絞れます（登録対象は常に全件です）。
   - 未登録の掛率集計コードがある場合は警告が表示されます。
4. `登録` を押すと kintone へ送信します。`登録キャンセル` を押すと送信しません。

### 5.3 確認なしで登録する

確認画面を出さずに登録する場合のみ `DRY_RUN` を OFF にして `実行` を押します。直接 kintone へ登録されるため、入力内容を十分確認してから実行してください。

### 5.4 kintone 登録の動き

- `検索キー` を更新キーとして 100 件単位で登録します（upsert）。
- 同じ検索キーのレコードがあれば更新、なければ追加します。
- 「加工名」は同一受注 No 内で重複を除いて「、」で結合して送信します（「工程」は送信しません）。
- 登録に失敗したレコードは `error\failed_yyyyMMdd_HHmmss.csv` に出力されます。

### 5.5 接続テスト・その他のボタン

- `TKS接続テスト`：OLAP ログインの疎通を確認します。
- `OLAP取得テスト`：登録や CSV 作成をせず、OLAP 取得だけを確認します。
- `加工名マスタ`：加工名マスタの管理画面を開きます（5.6 参照）。
- `得意先ヘッダー設定`：得意先ラベルと判定文字列を設定します。
- `古いファイル削除`：保存日数より古いログ等を削除します。
- `設定フォルダを開く` / `ログフォルダを開く` / `workフォルダを開く`：各フォルダを開きます。

> `TKS接続テスト` `OLAP取得テスト` や各フォルダボタン、ログ表示などのデバッグ項目は、設定でデバッグ表示を ON にしたときだけ表示されます（初期は非表示）。

### 5.6 加工名マスタ管理

`加工名マスタ` を押すと、加工名判定の元になるマスタを編集できます。`行追加` `行削除` のほか、`CSVインポート` `CSVエクスポート` `バックアップ作成` `バックアップから復元` が行えます。加工名の判定は掛率集計コードを優先し、コードが空の場合のみ掛率集計名称で判定します。

## 6. 設定

機能選択画面・Kintone 登録画面の `⚙`（設定）から共通設定を変更できます。

- **テーマカラー**：`システム` / `ライト` / `ダーク`。
- **デバッグ表示**：ON にするとデバッグ項目を表示します（ON にはパスワードが必要）。初期は OFF。
- **Kintone接続先**（Kintone 登録画面の設定）：`本番` / `テスト`。初期値は `本番`。
- **Teams通知**：登録結果の Teams 通知を有効化し、テスト用／本番用の Webhook URL を設定します。
- **バージョン情報**：バージョンネーム（1.4.10）・コードの確認、`更新確認` の手動実行。
- **高度な設定**：ログ保存日数（既定 30 日）、加工抽出ロジック／素板抽出ロジックの抽出条件を確認・変更します。`初期値に戻す` でテンプレートの値へ戻ります。

---

## 7. 更新

- 機能選択画面の表示時に自動で 1 回だけ更新確認します。新しいバージョンがあるときだけ確認ダイアログが出ます。
- 設定画面の `更新確認` から手動でも確認できます。
- 更新ダイアログで `はい` を選ぶと、署名済みインストーラをダウンロードしてアプリを終了し、サイレントで上書き更新します。

---

## 8. 困ったときに

- **ログインできない**：OLAP ログイン ID／パスワード、kintone ログイン情報を確認してください。
- **データが取得できない**：受注 No の入力（行ごと、または検索欄）を確認し、`取り直し` や `OLAP取得テスト` で再取得します。
- **登録に失敗する**：`error` フォルダの失敗 CSV と `logs` フォルダのログを確認してください。再実行時は検索キーで既存レコードを更新します。
- **指図書編集の内容が消えた**：編集内容は受注 No ごとに別管理されており、OLAP キャッシュ削除では消えません。`取り直し` でも保持されます。
