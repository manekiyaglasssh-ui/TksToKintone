# リリースノート

## バージョン 1.6.2

- TksToKintoneをバージョン1.6.2へ更新しました。

## バージョン 1.6.1

- TksToKintoneをバージョン1.6.1へ更新しました。

## バージョン 1.5.13

- SumatraPDFの導入方式を、アプリへの同梱からWindowsへのインストール方式へ変更しました。
- SumatraPDFがインストールされていない場合、新規インストール時と更新時のセットアップで自動導入するようにしました。
- アプリ更新後にSumatraPDFが見つからず印刷できない問題を修正しました。
- インストール済みのSumatraPDFを印刷処理で自動検出するようにしました。
- TksToKintoneをアンインストールしても、独立したアプリであるSumatraPDFは削除しません。

## バージョン 1.5.12

- 伝票へ表示する加工名を1～12行目ごとに変更できるようにしました。
- 指図書編集で、ドラッグ範囲に合わせた文字サイズ調整に対応しました。
- 小さい文字や細い線、小さいオブジェクトを選択・編集しやすくしました。
- テキストのリサイズハンドルで文字サイズを変更できるようにしました。
- お気に入りオブジェクトの配置位置を保存できるようにしました。
- 指図書編集画面から未保存の内容を直接プレビューできるようにしました。
- 反映先とお気に入りをドラッグ＆ドロップで並び替えられるようにしました。
- 指図書編集のプレビュー、短文テキスト編集、リサイズに関する不具合を修正しました。

## バージョン 1.5.11

- 伝票へ表示する加工名を設定画面から変更できるようにしました。
- 指図書編集で、ドラッグした範囲に合わせてテキストサイズを自動調整できるようにしました。
- テキストの右クリックメニューから編集状態へ移行できるようにしました。
- 小さいテキストを選択しやすいよう、クリック可能範囲を拡大しました。
- お気に入りオブジェクトに配置位置も保存できるようにしました。
- 指図書編集画面から、未保存の編集内容を直接プレビューできるようにしました。

## バージョン 1.5.10

- 日本語フォント、TTC内のスタイル別フェイス選択、文字ごとのglyph fallbackを見直し、指図書のPDF・プレビュー・印刷でフォントと文字装飾をより正確に反映するよう改善しました。
- 指図書編集画面の背景生成とフォント一覧取得を遅延・キャッシュし、画面を先に操作できるよう起動を高速化しました。
- 伝票一覧は最初の10件を表示した時点で操作可能にし、残りを10件単位で読み込むよう変更しました。
- Kintone登録前確認画面を先に表示し、OLAP・Kintone確認と後続行の準備をバックグラウンド化しました。全件の確認が完了するまで登録は実行できません。
- PDF生成・プレビュー・印刷時に保存済みの最新編集内容を再読込し、古い編集内容やプレビューキャッシュが使われる問題を修正しました。

## バージョン 1.5.9

- OP区分が「00」「01」「02」の明細だけ、単価列・金額列の上段に㎡を表示するようにしました。
- 指図書編集で、テキストのフォント、文字サイズ、太字を選択できるようにしました。
- 選択した書式は保存、再読込、Undo／Redo、伝票間コピー、PDF出力へ反映されます。
- よく使うフォントを☆／★ボタンでお気に入り登録し、1つのフォント一覧の上部から素早く選べるようにしました。お気に入りはアプリ設定として次回起動後も維持されます。
- 太字・斜体・下線・取り消し線を「装飾」メニューへまとめ、ショートカットと右クリックからも切り替えられるようにしました。装飾は保存、コピー、Undo／Redo、PDF出力へ反映されます。

## バージョン 1.5.8

- 受注Noの範囲指定で、`C405113` のような英字を含む受注Noに対応しました。
- 英字部分を維持し、末尾の数字部分を連番として一括取得できるようにしました。
- `AB001` のような先頭ゼロを含む受注Noの範囲指定にも対応しました。
